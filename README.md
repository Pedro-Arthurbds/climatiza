# Climatiza

Sistema web de operação de serviços técnicos, com clientes, endereços,
chamados, agenda, equipe e lembretes preventivos.

Consulte a documentação completa em [`docs/`](docs/index.md) ou execute
MkDocs localmente:

```bash
python -m pip install -r requirements-docs.txt
mkdocs serve
```

O site de documentação fica disponível em `http://127.0.0.1:8000`.
